# 자동 드라이브 저장 — 결정 사항 및 동작 규칙

승인일: 2026-10-22

## 1. 승인된 결정

| 항목 | 결정 |
|---|---|
| 디바운스 간격 | 마지막 변경 후 **3초** 동안 추가 변경이 없으면 저장 |
| 토큰 없을 때 | 팝업을 자동으로 띄우지 않음. **"🔒 로그인해서 동기화"** 배지를 누르면 로그인 → 즉시 동기화 |
| 수동 저장 버튼 | **상태 배지로 대체**. 배지를 누르면 즉시 동기화 |
| 충돌 방지 | 자동 저장과 함께 적용 — Drive 파일의 `modifiedTime` 비교 방식 |

## 2. 저장 위치 (변경 없음)

| 위치 | 키/파일 | 내용 |
|---|---|---|
| localStorage | `calendar_v6` | 일정 데이터 (변경 즉시) |
| localStorage | `calendar_sync` | 동기화 정보 `{ base, dirty, last }` (신규) |
| localStorage | `calendar_backup` | 충돌 해결 시 "드라이브 버전 불러오기"로 버려진 이 기기 데이터 1건 (신규) |
| Google Drive | `calendar_data.json` | 일정 데이터 |
| Google Drive | `cal_img_<id>.jpg` | 첨부 이미지 (기존과 동일하게 첨부 즉시 업로드) |

- `base`: 이 기기가 마지막으로 동기화한 시점의 Drive 파일 `modifiedTime`
- `dirty`: 이 기기에 Drive에 올리지 않은 변경이 있는지 여부 (새로고침해도 유지)
- `last`: 마지막으로 동기화에 성공한 시각

## 3. 동기화 규칙

동기화는 다음 경우에 실행됩니다.
- 일정 변경 3초 후
- 로그인(토큰 발급) 직후 → 앱을 열고 로그인하면 자동으로 최신본을 불러옴
- 앱이 다시 화면에 보일 때, 또는 화면에서 사라질 때(미저장 변경이 있는 경우)
- 네트워크가 다시 연결될 때
- 상태 배지를 누를 때

실행 순서:
1. 토큰이 없으면 → `login` 상태로 두고 종료 (팝업 없음)
2. Drive 파일의 `modifiedTime`을 조회
3. Drive 쪽이 `base` 이후 바뀌었다면
   - 이 기기에 미저장 변경이 없으면 → **조용히 불러오기**
   - 처음 동기화하는 기기이고 로컬 데이터가 비어 있으면 → 불러오기
   - 이 기기에도 미저장 변경이 있으면 → **충돌**: 사용자가 선택
     - "드라이브 버전 불러오기" (이 기기 변경은 `calendar_backup`에 1건 보관)
     - "이 기기 버전으로 덮어쓰기"
4. Drive 쪽 변경이 없고 이 기기에 미저장 변경이 있으면 → 업로드하고 `base` 갱신
5. 업로드 중에 생긴 변경은 다음 동기화에서 처리

## 4. 상태 배지

| 상태 | 표시 | 누르면 |
|---|---|---|
| saved | ✓ 저장됨 · N분 전 | 지금 동기화 확인 |
| pending | ● 저장 대기 | 지금 저장 |
| saving / checking | ⟳ 저장 중… / ⟳ 동기화 확인 중… | — |
| login | 🔒 로그인해서 동기화 (· 미저장 변경 있음) | 구글 로그인 → 동기화 |
| error | ⚠ 저장 실패 · 이 기기에 보관됨 | 재시도 |
| conflict | ⚠ 다른 기기 변경과 충돌 | 아래 선택 패널 사용 |

실패해도 에러 알림을 반복해서 띄우지 않습니다. 데이터는 localStorage에 남아 있다가, Drive에 접근 가능한 기기에서 동기화될 때 업로드됩니다. (회사 PC처럼 Drive 업로드가 막힌 환경 고려)

"↓ 불러오기" 버튼은 유지합니다. 미저장 변경이 있으면 확인을 받은 뒤 Drive 버전으로 덮어씁니다.

## 5. 알려진 한계

- 토큰은 메모리에만 있으므로, 앱을 새로 열거나 약 58분이 지나면 다시 로그인 배지를 눌러야 합니다. 완전 자동화하려면 서버 측 OAuth(refresh token)가 필요합니다.
- 앱을 닫는 순간에 시작된 업로드는 브라우저가 중단할 수 있습니다. 이 경우 `dirty`가 남아 있으므로 다음에 열 때 다시 업로드됩니다.
- 충돌 해결은 파일 단위(둘 중 하나 선택)이며, 항목 단위 병합은 하지 않습니다.
